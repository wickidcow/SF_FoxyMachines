# SF_FoxyMachines 1.0.3 — independent Chunk Loader policy

Distinct successor to immutable v1.0.2. No Slimefun item/research IDs, recipes, quota keys or existing saved block data are intentionally changed.

## Changes

- Independent `plugins/FoxyMachines/config.yml` `chunk-loading-mode: ONLINE` (default), `ALWAYS`, or `OFF`. It does not inherit Slimefun Legacy's Resonance Beacon setting.
- New placements use FoxyMachines-owned, removable Paper plugin chunk tickets. OFF hides Chunk Loader from the guide and rejects new placement without deleting old items.
- Existing persistent vanilla force-loaded chunks remain untouched unless an operator specifically audits and enables `migrate-legacy-force-loaded-chunks: true` after a full world backup; this one-time option is **false by default**. Unrelated force-loaded chunks are never automatically cleared.
- Offline-owner loader quota decrements use a persistent cumulative journal and replay-safe player PDC, while missing/unreadable ownership files fail closed. Stale loader tickets are checked only in already-loaded chunks without force-loading dormant worlds.

See [independent loader policy documentation](../CHUNK_LOADER_POLICY.md).
