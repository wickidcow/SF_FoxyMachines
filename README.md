## 🦊 What does FoxyMachines do?

FoxyMachines is a varied Slimefun addon that mixes technology, combat, magic, building utilities, and custom encounters.

### 👑 Bosses & mobs

- Pixie Queen
- Headless Horseman
- Pixie
- Helldog

### 🪄 Tools

Electric Wind Staff, Electric Fire Staff, Electric Fire Staff II, Berry Bush Trimmer, Poseidon's Fishing Rod, Remote Controller, Ghost Block Remover, Position Selector, Fill Wand, and Sponge Wand.

### ⚔️ Weapons & armor

Healing Bow, Cursed Sword, Celestial Sword, Elucidator, Acri Arcum, Aquatic Helmet, Resistant Chestplate, Fiery Leggings, and Light Boots.

### ⚙️ Machines & special content

Improvement Forge, Potion Mixer, Electric Gold Refinery, Chunk Loader, Boosted Rails, Forcefield Dome, Sacrificial Altar, Ghost Blocks, and other FoxyMachines content.

## 🧪 Slimefun Legacy maintenance

This fork keeps FoxyMachines recognizable while updating it for the modern Slimefun Legacy ecosystem. Maintenance work focuses on current Paper compatibility, safe API usage, build reliability, and preserving item IDs, recipes, mechanics, and saved data wherever practical.

Server owners should back up established worlds and plugin data before changing builds.
